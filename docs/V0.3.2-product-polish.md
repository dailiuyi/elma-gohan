## 首页

产品名统一为“ELMA 今天吃什么”。产品标题位于顶部左侧，顶部不再重复展示独立的 `ELMA`；标题下使用不对称细线，首页保留轻量流程线：

```text
定位附近 → 过滤风险 → 只给一家
```

距离与预算使用互不重叠的区间。下界不包含、上界包含：

```text
距离：[0,500] / (500,1000] / (1000,2000] / (2000,3000]
预算：[0,20] / (20,40] / (40,70] / (70,+∞)
```

首页默认选择 `500m 以内 + 人均 ¥21～40`。创建推荐请求通过可选的 `minDistance/minBudget` 表达下界；旧客户端不传下界时仍保持累计上限语义。价格缺失的餐厅继续保留，但不会获得“预算合适”理由。

## 高德 POI 分类

高德结果必须先通过餐饮身份判断，再运行细品类关键词映射：

- `VERIFIED`：typecode 与 type 根分类都明确为餐饮。
- `SUPPORTED`：其中一项明确为餐饮，另一项缺失且不冲突。
- `INFERRED`：官方分类缺失，但至少两个餐饮软信号成立。
- 明确属于服装、购物或其他非餐饮类别的 POI 直接丢弃；即使 typecode 缺失，非餐饮 type 词也优先否决，名称关键词不得覆盖。

分类可信度分别对 LowRegretScore 扣除 `0 / 6 / 18` 分。该状态是服务端内部排序信号，不扩展客户端 DTO；HIGH 风险过滤、TasteProfile、最多 6 家候选与 5 次 reroll 均保持不变。
