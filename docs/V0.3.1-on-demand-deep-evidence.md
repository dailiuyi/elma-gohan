# LowRegret V0.3.1：按需深度 Evidence

> 本文保留旧版行为记录；当前实现、配置与验收边界见 [Evidence v0.4](evidence-reliability-v0.4.md)。

## 目标与边界

- 应用版本：`0.3.1`
- 基础风险与推荐版本保持：`risk-v0.3`、`recommendation-v0.3`
- 深挖算法：`deep-risk-v0.1`
- 主推荐与 reroll 不调用百度 AI 搜索；只有用户点击“深挖一下这家”时查询。
- 只消费百度 AI 搜索返回的公开索引标题、URL、摘要和时间，不访问结果页面或评论区。

## 数据流

```text
当前推荐会话与匿名用户校验
→ 冻结当前 restaurantId、基础 Risk 与高德/百度 Evidence
→ 读取三来源 PostgreSQL 缓存
→ 缺失来源并行查询百度 AI 搜索（B站/小红书/大众点评）
→ HTTPS 白名单、URL 去重与 Web Entity Match
→ 透明关键词信号分析
→ deep-risk-v0.1（相对基础风险最多 ±10）
→ 返回独立深挖页
```

百度 AI 搜索部分或全部失败时仍返回基础判断，失败来源标记为 `UNAVAILABLE`。同一应用实例使用餐厅级 single-flight 合并并发首次请求。

## 搜索与匹配

每个缓存未命中的餐厅并行查询三个站点。第一轮使用“核心店名 + 一个分店/商圈短词”（去掉括号分店名和英文引号），固定 `edition=turbo`、`top_k=10`、`search_source=baidu_search_v2`、按来源站点过滤，以及 `search_recency_filter=month`；B站额外请求 video 模态。严格门店匹配后仍为 0 的来源最多追加一次不限时间查询，因此首次最多 6 次百度 AI 搜索调用。HTTP 失败不重试，外部总预算仍不超过 4 秒。日志分别记录 `rawResultCount` 与 `matchedResultCount`，不记录查询全文。

查询指纹包含 `baidu-ai-search-query-v0.2`，查询策略升级会自动令旧 Evidence 缓存失效，无需删除历史或手工清库。

结果必须来自 B站视频、小红书或大众点评 HTTPS 白名单域名。店名规范化后，完整命中可接受；模糊名称要求 bigram Jaccard 至少 `0.72` 且命中地址/商场/分店关键词。URL 去除查询与 fragment 后去重，标题、摘要和 URL 分别限制为 200、500 和 1000 字。

## 信号与风险

规则将公开摘要中的词语归为正面、负面、运营提醒与营销倾向。运营提醒按半个负面信号计算；营销倾向不直接加风险，只降低 Web confidence。公开摘要始终称为“公开线索”，不称为平台完整评价。

```text
sourceBalance = (negative + 0.5 × operational - positive) / signalTotal
coverage = min(1, relevantResultCount / 9) × availableSourceCount / 3
riskAdjustment = clamp(round(10 × globalBalance × coverage), -10, 10)
deepRiskScore = clamp(baseRiskScore + riskAdjustment, 0, 100)
```

Web 线索不能把原本非 HIGH 的餐厅单独推成 HIGH，分数最高限制为 60。无有效线索时调整为 0；有结果时置信度使用 `75%` 基础 confidence 与 `25%` Web confidence。

## API 与缓存

`POST /api/v1/recommendations/{id}/deep-evidence` 无请求体，要求匿名 UUID 请求头，只允许深挖该会话当前餐厅。响应返回基础/深挖风险、来源状态、信号摘要、一致度及每站最多 3 条链接，不返回搜索摘要全文。

Flyway V4 新增：

- `restaurant_deep_evidence`：按餐厅与来源缓存标准化 Web Evidence；正常/无数据 12 小时，不可用 5 分钟。
- `restaurant_deep_analysis`：缓存与 Evidence fingerprint 对应的分析 6 小时；最终分数仍与当前会话基础风险即时组合。

配置统一位于 `elma.deep-evidence.*`。生产密钥只由 `BAIDU_AI_SEARCH_API_KEY` 环境变量注入，不进入仓库或日志。跨实例 single-flight、后台任务、授权平台 Provider 与全文分析均留作后续扩展。
